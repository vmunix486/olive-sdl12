olive.c + SDL 1.2 running on Debian 3.1 on an Intel 386 with 32mb of RAM.
<br><br><br>

[olive.c](https://github.com/tsoding/olive.c) is a 2D/3D engine created by [Tsoding](https://github.com/tsoding) that's in a single file, even though it's 3D, it does everything on the CPU.

[SDL 1.2](https://github.com/libsdl-org/SDL-1.2) is a "[d](https://github.com/libsdl-org/SDL-1.2#:~:text=%2A%2A%2ADEPRECATED%2A%2A%2A%2C)[E](https://github.com/libsdl-org/SDL-1.2#:~:text=DEPRECATED)[p](https://www.libsdl.org/download-1.2.php)[R](https://github.com/libsdl-org/sdl12-compat#:~:text=strongly%20encourage%20you%20not%20to%20do%20that)[i](https://wiki.libsdl.org/SDL3/SDL12MigrationGuide)[C](https://wiki.libsdl.org/SDL2/MigrationGuide)[a](https://www.reddit.com/r/gamedev/comments/sezckj/how_can_i_learn_sdl_12_and_not_sdl_2/#:~:text=That%E2%80%99s%20a%20very%20out%20of%20date%20version%20of%20SDL%2E)[T](https://www.phoronix.com/news/sdl-compat-1.2.62)[e](https://github.com/libsdl-org/SDL-1.2#:~:text=DEPRECATED)[D](https://github.com/libsdl-org/SDL-1.2#:~:text=is-,deprecated)" version of [SDL](https://libsdl.org/) that I love for its simplicity and portability. Something about SDL 1.2 is that it does not support hardware acceleration.

Put two and two together and it's pretty good, and that's what I did with ~20 minutes one night, rewriting the [Japan example](https://github.com/tsoding/olive.c#:~:text=%2F%2F%20flag%5Fjp%2Ec) for SDL 1.2.
